# Glossary

> Project-specific terminology. Auto-generated by wiki-indexer.

| Term | Definition | See Also |
|------|-----------|----------|
| **Adoption (`--adopt`)** | Explicit install/update/reconcile mode that backs up conflicting user-owned or locally modified target files and `opencode.json` entries into `<target>/.manage-agents/backups/<id>/` before replacing them with pack-managed content. | [Pack Lifecycle & Target Safety](./concepts/pack-lifecycle-and-target-safety.md) |
| **Agent** | An OpenCode primary orchestrator or specialist subagent defined as a Markdown file with YAML frontmatter under `agents/` (or `agent/` / `mode/` before V2 normalization). | [Agent Editing, V2 Compatibility & Git Transactions](./modules/agent-editing-and-v2-compat.md) |
| **Archetype** | A pack configuration (`archetype: { callers, reference }` in `opencode-pack.json`, or inferred/user-configured callers) where primary orchestrator agents delegate tasks to subagents whose models and policies vary dynamically based on the caller's active model. | [Conditional Routing & Archetypes](./concepts/conditional-routing-and-archetypes.md) |
| **Authoring Kit** | Optional developer scaffolding installed into a pack repository (`manage-agents pack doctor --authoring-kit` or `pack onboard --authoring-kit`) consisting of `.opencode/skills/opencode-pack-authoring/SKILL.md` and `.github/workflows/validate-pack.yml`. | [Pack Onboarding, Doctor & Scaffolding](./modules/pack-onboarding-and-doctor.md) |
| **Bridge** | A deterministic translation of an OpenCode pack (and its transitive `requires` closure) into another AI coding harness format—either a **Claude Code plugin** (`bridges/claude-code/<name>`) or a **Codex layer** (`bridges/codex/<name>`). | [Claude Code & Codex Bridges](./modules/bridges.md) |
| **Bundle Hash (`bundleHash`)** | Deterministic `sha256:<hex>` digest computed by `computeEngineBundleHash()` over the engine's published files (excluding `.git`, `node_modules`, `dist`, `.manage-agents`, etc.) to verify release archive integrity during `self-update`. | [Launcher, Build & Self-Update](./modules/launcher-and-build.md) |
| **Caller** | A primary agent (listed in `archetype.callers`, `rule.callers`, or user `$callers`) whose active session model triggers subagent model routing and conditional `IF / OR` policy evaluation in `manage-agents-router`. | [Conditional Routing & Archetypes](./concepts/conditional-routing-and-archetypes.md) |
| **Catalog** | A workspace or source repository containing multiple packs arranged under `packs/<name>/opencode-pack.json` (or discovered up to `DISCOVERY_DEPTH = 4`). A single pack root is treated as a catalog of one. | [Pack Validation, Catalog & Virtual Packs](./modules/pack-validation-and-virtual-packs.md) |
| **Conditional Flow (`ConditionalRule` / `IF / OR` Flow)** | A Contract `1.1` routing rule (`flowDefaults` in `opencode-pack.json` or `$rules` in user `routing.json`) matching `OR` lists of `callers` and `triggers` (`*`, `provider`, or `provider/model`) to apply `then.models`, `then.tools`, `then.permissions`, and `then.delegations` effects at runtime. | [Archetypes, Conditional Flows & User Settings](./modules/routing-and-user-settings.md) |
| **Content Hash (`contentHash`)** | Combined SHA-256 digest stored in `lock.json` covering every installable file byte snapshot of a resolved pack. | [Dependency Resolver & Lockfile](./modules/resolver-and-lock.md) |
| **Contract 1.1** | The versioned specification (`contract/CONTRACT.md` and `contract/opencode-pack.schema.json`) governing valid pack layout, manifest fields, namespacing, references, and installation semantics; backward-compatible with `1.0` packs while adding `flowDefaults`. | [OpenCode Pack Contract 1.1 Reference](./api/pack-contract-reference.md) |
| **Contribution** | The normalized subset of `opencode.json` entries (`plugins`, `skills`, `instructions`, `mcp.servers`, `agents`, `commands`, `formatter`, `lsp`, `experimental`) owned by a single installed pack and recorded in `<target>/.manage-agents/installed.json`. | [Transactional Target Installer](./modules/target-installer.md) |
| **Desired State (`desired.json`)** | Target state file at `<target>/.manage-agents/desired.json` recording the root pack request specs (`[source/]pack[@range]`) explicitly requested by the user. | [User Settings, Target State & Environment Variables](./config/user-and-target-files.md) |
| **Drift** | Any discrepancy detected by `manage-agents status` (`targetStatus()`) between a target's on-disk files/`opencode.json` and the expected state derived from `desired.json`, `lock.json`, and user settings (`routing.json`, `overrides.json`). | [Pack Lifecycle & Target Safety](./concepts/pack-lifecycle-and-target-safety.md) |
| **Executable Hash (`executableHash`)** | Combined SHA-256 digest in `lock.json` covering all executable code bytes (plugins, tool modules, skill scripts) plus structured MCP/formatter/LSP command configurations in a pack; any change triggers user confirmation on update. | [Security & Trust Model](./concepts/security-and-trust-model.md) |
| **Executable Surface (`ExecutableSurface`)** | Inventory of code and external commands a pack can run (`plugins`, `pluginPackages`, `toolModules`, `skillScripts`, `mcpServers`, `externalCommands`), surfaced by `pack validate`, `resolve`, and install confirmation prompts. | [Pack Validation, Catalog & Virtual Packs](./modules/pack-validation-and-virtual-packs.md) |
| **FFI (`--experimental-ffi`)** | Foreign Function Interface flag required on Node.js (`>=26.4.0`) by `@opentui/core` for native terminal rendering; automatically injected via self-re-execution in `manage-agents.mjs`. | [Runtime & Tooling Dependencies](./dependencies/runtime-and-tooling-stack.md) |
| **`inherit`** | Special subagent routing target (`INHERIT = "inherit"`) indicating that the subagent should run on the same model as its caller rather than switching to a separate model. | [Conditional Routing & Archetypes](./concepts/conditional-routing-and-archetypes.md) |
| **Inspector** | The right-hand detail pane in the TUI Catalog workspace exposing six switchable tabs (`Info`, `Prompt`, `Name`, `Sec`, `Graph`, `Res`) for inspecting and editing the selected pack or agent. | [TUI Shell, Catalog Tree & Inspector](./components/tui-shell-and-catalog.md) |
| **Installed State (`installed.json`)** | Target state file at `<target>/.manage-agents/installed.json` tracking every managed relative file path (hash + owning pack), per-pack `opencode.json` contributions, and `createdSections`. | [Transactional Target Installer](./modules/target-installer.md) |
| **Journal (`journal.json`)** | Crash-recovery transaction log written to `<target>/.manage-agents/journal.json` before mutating a target; if a write is interrupted, the next target command automatically rolls back from the journal. | [Pack Lifecycle & Target Safety](./concepts/pack-lifecycle-and-target-safety.md) |
| **`listShare`** | User-configurable horizontal split ratio (`0.60` to `0.75`, default `2/3`) between the left list panel and right inspector panel in normal TUI layout mode, persisted in `$XDG_CONFIG_HOME/manage-agents/ui.json`. | [TUI Shell, Catalog Tree & Inspector](./components/tui-shell-and-catalog.md) |
| **Lockfile (`lock.json` / `PackLock`)** | Target state file at `<target>/.manage-agents/lock.json` pinning exact resolved pack versions, sources, Git commit revisions, `manifestHash`, `contentHash`, `executableHash`, and trust flags. | [Dependency Resolver & Lockfile](./modules/resolver-and-lock.md) |
| **`manage-agents-router`** | Built-in OpenCode V2 plugin (`runtime/plugins/manage-agents-router/`) automatically installed into `<target>/plugins/manage-agents-router/` with a generated `routing.json` when any installed pack has active archetype routes or conditional flows. | [Runtime Router Plugin](./modules/runtime-router-plugin.md) |
| **Model Tier (`TranslationTier`)** | Abstract capability bucket in `bridges/translation-config.json` (by default `planning`, `execution`, and `light`) mapping agent roles to target-specific Claude Code (`opus`, `sonnet`, `haiku`) and Codex (`model` + `reasoningEffort`) targets. | [Cross-Harness Pack Translation](./concepts/cross-harness-translation.md) |
| **Namespace Rule** | Contract `1.1` requirement that every non-native file in a pack reside under `<dir>/<pack-name>/**` (or `tools/_<pack-name>_*`) so multiple packs can merge cleanly into one shared OpenCode target directory without path collisions. | [OpenCode Pack Contract 1.1 Reference](./api/pack-contract-reference.md) |
| **`opencode-pack.json` (`PackManifest`)** | Required root manifest file of an OpenCode pack declaring `contract`, `name`, `version`, `description`, and optional `requires`, `archetype`, `routingDefaults`, and `flowDefaults`; never copied into the installed target. | [OpenCode Pack Contract 1.1 Reference](./api/pack-contract-reference.md) |
| **Overrides (`overrides.json`)** | Scoped user settings file (`$XDG_CONFIG_HOME/manage-agents/overrides.json`) that patches allowed YAML frontmatter fields of installed agents and commands during `reconcile` without modifying source pack files. | [Archetypes, Conditional Flows & User Settings](./modules/routing-and-user-settings.md) |
| **Pack** | A distributable unit of OpenCode configuration (`agents/`, `commands/`, `skills/`, `plugins/`, `themes/`, `tools/<pack>/`, `opencode.json(c)`, `AGENTS.md`) accompanied by `opencode-pack.json`. | [Project Overview](./overview.md) |
| **Pack Doctor** | Diagnostic and auto-repair subsystem (`manage-agents pack doctor` / `d` in TUI) that inspects a pack for Contract `1.1` errors/warnings, V1 frontmatter legacy keys, un-namespaced files, and missing authoring kit files, repairing fixable drift on `--fix`. | [Pack Onboarding, Doctor & Scaffolding](./modules/pack-onboarding-and-doctor.md) |
| **Pinned Subagent** | A subagent with a fixed `model` in its frontmatter or via `models pin` (stored in `overrides.json`); `manage-agents-router` skips pinned subagents when routing models (`models unpin` sets `model: null` override so routing applies even if the pack frontmatter specifies a model). | [Conditional Routing & Archetypes](./concepts/conditional-routing-and-archetypes.md) |
| **Released File** | A previously pack-managed file in `<target>` that the user modified locally and that is no longer provided by any installed pack on `uninstall`/`update`; left untouched on disk and removed from `installed.json`. | [Pack Lifecycle & Target Safety](./concepts/pack-lifecycle-and-target-safety.md) |
| **Repository Transaction (`repositoryTransaction`)** | Workspace edit wrapper that verifies clean Git status, branch/identity/lock state, and symlink-free local paths before creating an optional hook-free, unsigned, path-scoped local Git commit when `--auto-commit` is enabled. | [Agent Editing, V2 Compatibility & Git Transactions](./modules/agent-editing-and-v2-compat.md) |
| **Source (`Source`)** | A local directory (`kind: "local"`) or Git repository (`kind: "git"`) registered in `$XDG_CONFIG_HOME/manage-agents/sources.json` from which packs are discovered. | [Sources & GitHub Integration](./modules/sources-and-github.md) |
| **Target** | An OpenCode configuration directory (default `$XDG_CONFIG_HOME/opencode`, i.e., `~/.config/opencode`) into which `manage-agents` installs, merges, and reconciles packs. | [Transactional Target Installer](./modules/target-installer.md) |
| **`terminalSafeText`** | Sanitization helper (`src/utils/terminalText.ts`) with highest fan-in across the codebase; strips ANSI CSI, OSC, and C0/C1 control sequences and bounds string length before displaying untrusted pack text in the terminal. | [Security & Trust Model](./concepts/security-and-trust-model.md) |
| **Trigger** | A caller model selector in `routingDefaults` or conditional rules: exact `"provider/model"` (specificity 2), `"provider"` (specificity 1), or wildcard `"*"` (specificity 0). | [Conditional Routing & Archetypes](./concepts/conditional-routing-and-archetypes.md) |
| **Unresolved Reference (`UnresolvedReference`)** | A static relative import, plugin path, skill path, instruction path, or `{file:...}` token in a pack with `requires` whose target file is not in the pack itself and must be satisfied by one of its transitive dependencies during resolution. | [Dependency Resolver & Lockfile](./modules/resolver-and-lock.md) |
| **V1 / V2 Frontmatter (`v2Compat`)** | Compatibility layer translating legacy OpenCode V1 agent frontmatter (`max_steps`, `disable`, `prompt`, `temperature`/`top_p`, object-shaped `permission`, separate `variant`) to native OpenCode V2 frontmatter (`steps`, `disabled`, `system`, `provider/model#variant`, ordered `permissions` array `[{ action, resource, effect }]`). | [Agent Editing, V2 Compatibility & Git Transactions](./modules/agent-editing-and-v2-compat.md) |
| **Variant (`#variant`)** | Model thinking/reasoning effort suffix in OpenCode V2 model references (`provider/model#variant`, e.g. `high`, `max`, `minimal`), configured via `tune` or the TUI Parameter Tuning modal. | [Authoring, Tuning & Bridge Modals](./components/authoring-and-bridge-modals.md) |
| **Virtual Pack (`0.0.0-virtual`)** | An in-memory Contract-compatible pack synthesized by `virtualPacks.ts` from a directory or Git repository containing Markdown agents or `.opencode/` resources without an `opencode-pack.json` manifest, allowing immediate TUI browsing, installation, routing, or one-step `pack onboard` conversion. | [Pack Validation, Catalog & Virtual Packs](./modules/pack-validation-and-virtual-packs.md) |
| **Workspace** | The local pack catalog (`packs/<name>/opencode-pack.json`), single pack directory (`opencode-pack.json`), or virtual pack directory targeted by TUI edits and workspace CLI commands (`create`, `lint`, `fix-names`, `audit`, `tune`, `bridge`). | [CLI Command Reference](./api/cli-reference.md) |
